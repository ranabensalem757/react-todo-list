# 📋 React Todo List

A clean and professional Todo List web application built with React and Tailwind CSS.

## ✨ Features

- ✅ Add new tasks
- 🗑️ Delete tasks
- ☑️ Mark tasks as completed (with strikethrough)
- 💾 Tasks persist after page refresh (saved in localStorage)
- 🔢 Counter for tasks added per session (resets on refresh)
- 📊 Counter for total deleted tasks (persists via localStorage)

## 🛠️ Tech Stack

- **React** — UI library
- **Vite** — Build tool and dev server
- **Tailwind CSS v4** — Styling
- **localStorage** — Data persistence

## 🚀 Getting Started

### Prerequisites

Make sure you have installed:
- [Node.js](https://nodejs.org)
- [pnpm](https://pnpm.io)

### Installation

1. Clone the repository:
```bash
git clone https://github.com/ranabensalem757/react-todo-list.git
```

2. Navigate to the project folder:
```bash
cd react-todo-list
```

3. Install dependencies:
```bash
pnpm install
```

4. Start the development server:
```bash
pnpm run dev
```

5. Open your browser at the local URL shown in your terminal
